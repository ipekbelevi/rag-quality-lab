# Troubleshooting and Error Codes

## Error codes

| Code | Meaning | What to do |
|------|---------|------------|
| E-11 | Water tank not detected | Remove the water tank and push it back firmly until it clicks. |
| E-17 | LatteCore milk sensor error (Forte only) | Remove and wash the milk carafe, dry the sensor contacts, and reattach the carafe. |
| E-23 | Pod not recognized | Use an undamaged Belevico Pod. Third-party pods are not supported. |
| E-31 | Overheating | Unplug the machine and let it cool for 30 minutes. |
| E-42 | Pump failure | Stop using the machine and contact support. This is usually covered by warranty. |

If an error code comes back after following these steps, contact support with the error code and your order number.

## Light signals

- Blinking blue: the machine is in Wi-Fi pairing mode.
- Orange drop icon: descaling is due soon.
- Blinking red: descaling is overdue.
- Blinking white: the machine is heating up.

## Coffee is too weak or too cold

- Weak coffee: check that you are using the right button for your blend (espresso for intensity 8 and above). Descale the machine if it has not been descaled in the last 3 months.
- Cold coffee: run a hot water cycle without a pod to preheat the cup and the brewing unit.

## Machine does not connect to Wi-Fi

Make sure your network is 2.4 GHz. Belevico machines do not support 5 GHz Wi-Fi. Restart pairing by holding the power button for 5 seconds.
